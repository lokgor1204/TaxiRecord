☁️ 點樣擺上 GitHub 並確保更新唔會洗走紀錄？

✅ 點解更新 GitHub 程式碼唔會刪除紀錄？

因為所有編更紀錄都係儲存在獨立嘅 Google Firebase 雲端資料庫，而唔係寫死喺 HTML 檔案入面。無論你點樣修改網頁介面或者更新 GitHub 程式碼，雲端資料庫入面嘅司機紀錄都會 100% 完整保留！

部署到 GitHub Pages 步驟：

  1. 前往 Firebase Console 建立一個免費專案，並開啟 Firestore Database（選擇測試模式或設定讀寫權限）同 Authentication（開啟「匿名登入 Anonymous」）。
  2. 喺 Firebase 專案設定中複製你嘅 firebaseConfig 貼入本網頁程式碼嘅指定位置。
  3. 喺 GitHub 建立一個新 Repository，將呢個檔案改名為 index.html 並上傳。
  4. 進入 GitHub Repository 的 Settings > Pages，將 Branch 設為 main 並按 Save。
  5. 幾分鐘後就會得到一條專屬網址，將網址 Share 畀其他同事，大家就可以一齊睇同編輯同一個編更表！
